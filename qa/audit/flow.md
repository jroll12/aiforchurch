## Checked, no problem found (summary)
- **Register:** all section 7 behavior and the seven messages; error linking; focus on the first invalid field; saved state; restore with the same code.
- **Review:** every field shown; Edit links keep data; total follows seats; a double click sends once; the failed-send error state; the payload format; redirect to Register when nothing is saved.
- **Confirmation:** the three states with fallback to pending; retry keeps the code without resending; paid clears attendees; the code survives a cross-origin payment round trip; the mailto forward link; no calendar link.
- **Questions:** validation, success, error, a double click sends once, honeypot.
- **Network and build:** only the site, fonts.googleapis.com and fonts.gstatic.com in both builds; no other scripts, localStorage or cookies; no `__mock` URLs in dist/; every internal link returns 200.
- **Production:** the pay, retry and send buttons are disabled; forced clicks send nothing.

## Not checked
- Real providers: redirect, cancel and CORS behavior simulated only.
- Safari and Firefox back/forward cache; real phones.
- Whether Chrome restores sessionStorage when a closed tab is reopened.
