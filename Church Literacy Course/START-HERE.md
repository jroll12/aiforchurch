# Start here

This pack builds the public site from the Direction C design. It is separate from the course content repo (roloff-course-kit). Run the two in two terminals at the same time: neither needs the other until the member area is built.

1. Unzip into a NEW folder, not the course repo, and run `git init`.
2. Optional: if the Design canvas lets you export PNG or PDF, put images of the six Direction C boards in design/screenshots/. Name them like the files in design/.
3. In a terminal: `cd` into the folder, run `claude`, and paste the contents of SITE-KICKOFF-PROMPT.md.
4. Claude Code posts a plan and waits. Answer its one question if it asks one, then say go.
5. After Stage 1, read qa/stage1-report.md. For an independent review, open a fresh session and paste qa/audit-brief.md.

What this pack does not contain: the Phase 2 member area, the facilitator tools, any real prices, dates or venue, and any payment or form account. Those are placeholders and config values.
