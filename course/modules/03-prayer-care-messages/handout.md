## Prompts to paste

Step 1, guide and log pasted below:

```
I format our church's prayer chain messages. Below are our prayer chain guide and this week's prayer log. Do not write any message yet. List each request with its share level, and which may go in the whole-church email.
```

Step 2:

```
Write the whole-church prayer chain email for Sunday, March 15, in the guide's format. Use only rows marked "whole church", and only the words in the request column. Never use the private or office_note columns. Add no updates or details not in the log. If someone else gave a request for the person, mark it [CONFIRM]. Then add a permission table: one row per detail, with its log row and share level.
```

Step 3:

```
Now write a get-well card for Ray Okafor, two or three sentences, signed "Your Maple Street Church family". Use only what he shared with the whole church. If unsure a detail was agreed to, leave it out or mark it [CONFIRM].
```

Step 4 is yours. Check each line of the email and card against its log row. The log wins over Claude’s table. A detail with nothing to check against comes out or gets [CONFIRM]. At work, ask the person before sending.

## Permission check

- [ ] Each request line is the name, then that row’s request words.
- [ ] Nothing from the private column or office note.
- [ ] Only rows whose share level in the log is whole church.
- [ ] Every detail has a row in the permission table.
- [ ] A request someone else gave is marked [CONFIRM] or left out.
- [ ] No pastor-only or do-not-share request, not even unnamed.
