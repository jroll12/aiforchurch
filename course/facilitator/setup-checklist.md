## How to fill [FILES LINK]

The handouts say [FILES LINK] until the workshop decides how attendees get the practice files. Which option to use is [CONFIRM]. Whatever you choose, share only `samples/` and `handout.md`, never `examples/`.

| Option | Good | Not so good |
| --- | --- | --- |
| **A download page on the workshop site** | One address that lasts. Easy to print. Works after the workshop. | The page has to be designed and built first, and the site must not link to it until it exists. A zip file is awkward on a phone. Anyone with the address can download the files, which is fine only because every file is FAKE. |
| **A shared folder** (a cloud drive link, view only) | Quick to set up and to update. Each file opens on its own, so a phone user can open it and copy the text. | Some services ask people to sign in, or push their own app [CONFIRM for the service chosen]. Needs the Wi-Fi to work. Adds an outside service to the day. |
| **USB sticks** | Works with no Wi-Fi. | Do not work on most phones and tablets. Some church laptops block USB sticks [CONFIRM]. Cost, and getting them back. Files cannot be updated after copying. |
| **Emailed before the day** | Files are on the laptop before anyone arrives. | Someone has to send the pre-workshop email [CONFIRM who]. Attachments can land in spam. People forget to download them. |

A sensible mix is a shared folder as [FILES LINK], with the same files on a few USB sticks and printed sample files at each table as backup [CONFIRM].
